# Payments Jobs Board

Статичний сайт, що збирає відкриті QA та Product вакансії у ~30 payment/fintech компаніях
(Solidgate, Ecommpay, payabl., WhiteTech, Paysafe, Praxis, GR8 Tech тощо) з фільтрами по позиції,
рівню (Junior/Middle/Senior) та компанії, орієнтовною вилкою ЗП за регіоном. Компанії з Кіпру
показуються першими.

Живе на claude.ai (миттєво, без налаштувань): https://claude.ai/artifact/CSdzAzEyCjiPYwZzudNeLZ

## Як це працює

- `scripts/scrape.mjs` — кожні 4 години збирає вакансії з Djinni.co та офіційних career-сторінок
  (ATS API: Greenhouse, Lever, Teamtailor, Workable), пише результат у `data/jobs.json`.
- `scripts/enrich.mjs` — для кожної вакансії визначає рівень (`levels`, за ключовими словами в
  назві — вакансія може мати кілька, напр. "Middle/Senior"), регіон (`region`: `ua`/`eu`/`uk`/`us`/
  `other`, за локацією або країною компанії) і рахує орієнтовну вилку ЗП (`salaryEstimate`,
  $/міс) — базові цифри з опитування DOU по QA (Junior ~$890, Middle ~$1900, Senior ~$3200),
  помножені на регіональний коефіцієнт. Це **оцінка, не дані з тексту вакансії** — на сайті це
  явно підписано.
- `.github/workflows/scrape-jobs.yml` — GitHub Actions, що запускає скрапер кожні 4 години і
  комітить оновлений `data/jobs.json`.
- `data/jobs-indeed.json` — окремий файл з тим самим набором полів, який оновлює **не** GitHub
  Actions, а вручну, на запит, через офіційний Indeed MCP-конектор (пряме HTTP-скрапіння
  indeed.com блокується їхнім анти-бот захистом — підтверджено, HTTP 403 — тож легальний шлях
  тільки через конектор). Дивись розділ нижче.
- `index.html` / `styles.css` / `app.js` — статичний фронтенд без збірки. Фетчить дані напряму з
  `raw.githubusercontent.com` (абсолютні URL на `master`), тому ті самі три файли однаково
  працюють і на GitHub Pages, і як claude.ai Artifact. Лічильник переглядів (у шапці сайту, скидається щодня) —
  через безкоштовний `abacus.jasoncameron.dev`, спільний для обох дзеркал.

Кожне джерело обгорнуте окремо: якщо одне джерело падає, інші все одно відпрацьовують, і сайт не
втрачає вже зібрані дані.

## Indeed-дані (окремий механізм, поки що ручний)

Пряме HTTP-скрапіння Indeed заблоковане на рівні їхнього анти-бот захисту (перевірено, HTTP 403),
а легальний Publisher API Indeed закритий для сторонніх розробників. Легальний шлях — офіційний
Indeed MCP-конектор, підключений у вашому акаунті Claude.

**Спроба автоматизувати це через щоденну Claude-рутину (Routine) не вдалася з технічної причини**:
будь-яка сесія, яку створює/будить Routine (навіть з `persistent_session_id`), стартує з мінімальним
набором дозволених інструментів (`Bash`/`Write`/`Edit`/`Read`/`Glob`/`Grep`) — перший же виклик
MCP-інструменту (навіть `add_repo`, не кажучи вже про сам Indeed-конектор) впирається в запит на
дозвіл, підтвердити який нема кому, бо сесія непідконтрольна людині. Параметр `connectors` у
`create_trigger` для цього акаунту теж недоступний ("not available for this organization").
Тобто зараз немає способу дати запланованій фоновій сесії доступ до Indeed-конектора без живої
людини, яка тисне "Approve" в інтерфейсі claude.ai.

Тому `data/jobs-indeed.json` наразі — це разовий знімок, зроблений напряму мною в інтерактивній
сесії (де конектор працює без обмежень): 6 пошукових запитів (QA/Product, payments/fintech,
кілька назв компаній, US/GB/DE) — **жодна з ~30 відстежуваних компаній зараз не має вакансій на
Indeed** (чесний нульовий результат, не збій пошуку). Схема файлу готова, тож оновити можна в
будь-який момент — попросіть мене (чи будь-яку сесію з доступом до Indeed-конектора) повторити
пошук і закомітити результат.

Якщо потрібна саме автоматична щоденна Indeed-автоматизація без ручного втручання — реальний шлях:
або (а) налаштувати Routine з конектором напряму в інтерфейсі claude.ai (там може бути інша логіка
видачі дозволів, ніж через API), або (б) перейти на легальний job-aggregator API без прив'язки до
сесії (наприклад Adzuna — безкоштовний ключ, звичайний HTTP-запит, тож працює з GitHub Actions так
само, як Djinni/ATS-джерела зараз).

## Локальний запуск

```bash
npm install
npm run scrape        # генерує data/jobs.json
python3 -m http.server # відкрити http://localhost:8000
```

## Додати нову компанію

Додайте запис у `scripts/companies.json`: `name`, `aliases` (варіанти написання назви, як вони
можуть зустрічатись на Djinni), `careersUrl`, `ats` (`greenhouse` / `lever` / `teamtailor` /
`workable` / `ashby` / `custom` / `unknown`), `atsSlug` (якщо ATS підтримується напряму),
`hqCountry`, `isCyprus`.
